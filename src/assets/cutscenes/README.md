# ROGUE.exe confrontation panels

Each PNG is a transparent 192×192 visual-novel panel. They are ordered by
filename for use over the existing Sector 8 or Sector 9 background:

- `rogue-entrance-01.png` through `rogue-entrance-04.png`: Sector 8 first
  direct appearance, from composed calm presence to close confrontation.
- `rogue-final-01.png` through `rogue-final-04.png`: Sector 9 finale, from
  peak corruption to a visibly fragmented defeat.

These are composition placeholders built from the delivered `rogue-calm.png`
and `rogue-corrupted.png` sprites. They preserve that existing character
design and can be replaced panel-for-panel with external-design exports later.
